Privacy Policy

Last updated: 27 September 2026

What Admin Brain is. A personal planning tool operated by its single owner. It is not a public service and has no users other than the owner.

What it accesses. With the owner's explicit Google sign-in consent, it uses the Google Calendar API to create, update and delete calendar events on the owner's own calendar, and to read the owner's calendar timezone setting. It requests no other Google data.

What it stores. An access token, held on the owner's private server, used only to perform the actions above. Calendar data is not copied, shared, sold or used for advertising or analytics.

Third parties. None. No data is transferred to any third party.

Revoking access. The owner can revoke access at any time at myaccount.google.com/permissions; the stored token then stops working.

Google API Services User Data Policy. Admin Brain's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
