Admin Brain — Privacy Policy

Last updated: 27 September 2026

1. Who we are

Admin Brain is a personal planning tool operated by a single individual (the "owner"). It is not a commercial product, it is not offered to the public, and it has no users other than the owner. Contact: a0508465481@gmail.com.

2. What the tool does

Admin Brain reads the owner's own project activity (for example, the owner's GitHub issues and the owner's Slack workspace) and turns it into a schedule: it creates, updates and deletes time blocks, deadline markers and reminders on the owner's own Google Calendar, so that the owner receives alarms on their devices.

3. Google user data we access

With the owner's explicit consent via Google sign-in (OAuth 2.0), Admin Brain requests two Google Calendar API permissions:

  • calendar.events — to view, create, change and delete events on the owner's calendars. Used to write the owner's schedule and to read back events the tool itself created, so it can update or remove them.
  • calendar.settings.readonly — to read the owner's calendar timezone setting, so that events are placed at the correct local time when the owner travels.

The tool requests no other Google data. It does not access Gmail, Google Drive, Contacts, Photos or any other Google service.

4. How we use the data

Calendar data is used exclusively to build and maintain the owner's own schedule and reminders. It is never used for advertising, profiling, analytics, training of machine-learning models, or any purpose other than the one described above.

5. What we store, and where

The tool stores a Google OAuth access/refresh token on a private server controlled by the owner, protected by file-system permissions, so that it can perform the actions in section 3 without asking the owner to sign in every time. It may keep a short-lived local cache of the events it created (their identifiers and content) purely to avoid creating duplicates. No copy of the owner's other calendar data is retained.

6. Sharing with third parties

None. Google user data is never sold, rented, shared or transferred to any third party, and is not transmitted to any service other than Google's own Calendar API.

7. Data retention and deletion

Events created by the tool remain on the owner's calendar until the tool or the owner deletes them. The stored token is deleted when the owner removes it from the server or revokes access (section 8), at which point the tool can no longer access any Google data.

8. Revoking access

The owner can revoke Admin Brain's access at any time at myaccount.google.com/permissions. Revocation takes effect immediately.

9. Security

Credentials are stored with restricted permissions on a private server; all communication with Google uses HTTPS; access is limited to the two scopes listed in section 3.

10. Google API Services User Data Policy

Admin Brain's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

11. Changes to this policy

Any change will be published on this page with an updated date.
