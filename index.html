Admin Brain

Admin Brain is a personal planning tool used by one person: its owner. It is not a public service and has no other users.

What it does

Every day, Admin Brain reads the owner's own work signals — open GitHub issues and pull requests on the owner's projects, and messages in the owner's Slack workspace — and turns them into a realistic schedule. It then writes that schedule into the owner's Google Calendar:

  • Time blocks for focused work on each project, at the owner's local time wherever they are.
  • Deadline markers with reminders 3 days, 1 day and 1 hour before.
  • Recurring personal reminders the owner has asked for.

When the underlying work changes — a pull request is merged, an issue is closed, a meeting is added — the calendar is updated to match. Events the tool created earlier are updated or removed by the tool itself; nothing else on the calendar is touched.

How it uses Google Calendar

With the owner's consent, the tool uses the Google Calendar API to create, update and delete events on the owner's own calendar, and to read the owner's calendar timezone. It requests no other Google data and shares nothing with third parties. Full details: Privacy Policy.
